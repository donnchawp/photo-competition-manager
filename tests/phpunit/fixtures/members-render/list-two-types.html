Import Members from CSV

Upload a CSV file to import multiple members at once. Existing members (matched by email) will be updated.


CSV format: name,email,grade,active (active: 1=active, 0=inactive)
Grade: one of the grades in Settings, by name or slug. New members need one. Leave it blank to keep an existing member's grade.
Types: optional column of competition type names separated by semicolons. It replaces the member's types. Leave it out to keep an existing member's types; new members get none.
